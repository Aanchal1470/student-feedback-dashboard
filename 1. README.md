# Student Feedback Dashboard

A web-based Student Feedback Dashboard built using Python, Flask, SQLite, HTML, CSS, and JavaScript.

## Features
- Student feedback submission
- Feedback stored in an SQLite database
- Sentiment analysis using TextBlob
- Dashboard showing feedback statistics and ratings
- Automated tests using Python unittest
- Docker containerization
- Jenkins CI/CD pipeline

## Technologies Used
- Python and Flask
- SQLite
- HTML, CSS, JavaScript
- TextBlob
- Docker
- Jenkins
- GitHub

## How to Run Locally

1. Install Python.
2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Run the application:

   ```bash
   python app.py
   ```

4. Open http://localhost:5000 in your browser.

## Run Automated Tests

```bash
python -m unittest test_app
```

## Docker

Build the image:

```bash
docker build -t student-feedback-dashboard .
```

Run the container:

```bash
docker run -d --name feedback-dashboard -p 5000:5000 student-feedback-dashboard
```

## CI/CD

Jenkins fetches the code from GitHub, installs dependencies, runs automated tests, builds a Docker image, and starts the application container.
